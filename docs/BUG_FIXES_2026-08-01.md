## 部署前必须完成

GitHub production Environment 中必须配置并轮换：

- `ADMIN_LOGIN_SECRET`
- `TOKEN_SIGNING_SECRET`
- `RUNTIME_MASTER_KEY`

三个值必须彼此独立。旧 `LICENSE_ADMIN_PASSWORD` 不应继续承担令牌签名或运行包加密用途。由于 Secret 不应写入仓库，本次提交只能修改代码和工作流，不能替用户生成或读取线上 Secret。

## 验收门槛

合并前必须满足：

1. `Security and compatibility regression` 全部通过。
2. Android release lint/build 通过。
3. Worker 本地迁移和 dry-run 通过。
4. 仓库不再跟踪 `build/`、`.class`、`.dex`、APK 或签名材料。

合并并配置生产 Secret 后，部署工作流还会执行真实生命周期验收。未通过时不得发布正式 APK。
